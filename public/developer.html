The four-step pattern

Your API key never leaves your backend. The applicant receives only a temporary, one-session flow link.

01

Create applicant

Use document-sourced identity, or declare an identity your product already holds for cross-checking.

02

Create session

Choose Level 1, 2 or 3 and receive flow_url plus an expiry.

03

Hosted flow

Consent, document scan, selfie, liveness and proof of address run on the applicant’s phone.

04

Decision

Receive session.completed by signed webhook, or poll the Sessions API.

import { KycClient } from './kyc.mjs';

const kyc = new KycClient({ apiKey: process.env.KYC_API_KEY });

const applicant = await kyc.createApplicant({
  country: 'NG',
  identitySource: 'document',
  externalRef: 'user_12345',
});

const session = await kyc.createSession({
  applicantId: applicant.id,
  level: 2,
  expiresHours: 24,
});

// Send only this temporary link to the applicant:
redirectApplicantTo(kyc.absoluteFlowUrl(session));

Choose your integration

The same hosted-flow contract works across product surfaces. The differences are how the person reaches the flow and how your product learns that it finished.

Website

Redirect or new tab

Your signed-in page asks your backend to create a session, then navigates to the flow. When the user returns, the page asks your backend for the verified status — never a URL parameter.

Mobile app

Browser handoff

Your app calls your backend, then opens the flow in the system browser, an iOS in-app browser surface or an Android Custom Tab. Refresh status on resume or through your own push.

OpenAPI tools

Webhooks that can be trusted

Every delivery carries an event header and an HMAC signature over the exact raw body. Verify first, acknowledge fast, then do your product’s work.

Events

Implemented event set

session.completed, case.opened, case.decided, applicant.deleted and screening.hit_new. Failed deliveries retry, dead-letter, and can be replayed from the API or dashboard.

JavaScript SDK

Verify in a few lines

verifyWebhookSignature(
  process.env.KYC_WEBHOOK_SECRET,
  rawBody,
  req.headers['kyc-signature'],
  { maxAgeSec: 300 }
);
